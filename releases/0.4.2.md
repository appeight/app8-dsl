Patch release of the iOS + Android train (spec: https://github.com/appeight/app8-dsl/releases/tag/0.4.2).
- iOS: a collection whose `data` reads from its cell's `item` (e.g. `{{item.products}}` in a vertical shop list) re-resolves when the outer cell is reused for another item. Before, it kept the previous item's data, so a shelf could show another section's products or stay blank after a section with none. Map annotations bound to `item` had the same fix.
- Android: `App8Instance.navigate(...)` lets the host push, pop, pop to root, dismiss, select a tab and complete a flow, like posting a NavigationRequest on iOS; `currentFlowId` is public.
- Android: `style.blendMode` (view and image styles, all 16 DSL values) now draws, matching iOS `layer.compositingFilter`.
