Patch release on 0.5.3 (spec: https://github.com/appeight/app8-dsl/releases/tag/0.5.0). All SDKs move to 0.5.4 together.
- iOS: pagers bound to the same `currentPageVariable` (for example a product image carousel and a full-screen gallery sharing `galleryPage`) no longer fight over it. A pager writes the variable only when its own page changes, follows the variable only up to the pages it has, and no longer stays muted after an interrupted scroll. Fixes page dots that froze while swiping the carousel and a likely crash from the re-entrant writes. Android already had this fix in 0.5.3.
- iOS: `pageControl` draws media-style page dots: a dark blurred capsule with white dots, the current one solid and the others at half opacity, matching the web renderer. `pageIndicatorTintColor` and `currentPageIndicatorTintColor` are not applied on iOS.
