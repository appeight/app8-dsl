Patch release on 0.7.1. All SDKs move to 0.7.2 together (iOS, Android, web renderer). `DSL_VERSION` stays 1.1.
- Photos ([photos.md](../docs/photos.md)): the `capturePhoto` action takes a photo with the camera or picks one from the library (`source`: `camera`, `library`, `cameraOrLibrary`; `camera`: `back` / `front`; optional `aspectRatio` center crop, `maxDimension` (1600), `quality` (0.8)). It stores an upright, downscaled JPEG without metadata on the device and returns a `photo://<id>` reference: `resultVariable`, `onSuccess` with `photo` (`ref`, `width`, `height`, `createdAt`, `source`), `onCancel`, `onError` with `error.code` (`permissionDenied`, `unavailable`, `failed`).
  - An `image` whose `url` (or `name`) is a `photo://` reference shows the stored photo; a deleted or unknown photo draws nothing.
  - `deletePhoto` removes a photo. At launch the engine removes photos older than an hour that no persisted variable mentions.
  - `App8.clearPersistedData()` also removes every app's photos (the account reset).
  - Storage per app id: iOS `Application Support/app8/<appId>/photos`, Android `filesDir/app8/<appId>/photos`, web IndexedDB `app8:<appId>:photos`.
  - System UI: iOS action sheet, `UIImagePickerController` camera, `PHPickerViewController` library; Android Material 3 bottom sheet, the system camera app (`ACTION_IMAGE_CAPTURE` through the engine's FileProvider), the Photo Picker; web renderer in-page camera (`getUserMedia`, file picker fallback) and file picker.
  - Hosts: iOS apps add `NSCameraUsageDescription` to `Info.plist` (without it the camera reports `unavailable`). Android hosts need nothing; a host that declares `CAMERA` gets the permission asked first.
  - 0.7.0 and 0.7.1 skip both actions (unknown action types) and draw `photo://` images empty; earlier iOS and Android releases reject screens that contain them.
- Android: the engine manifest adds a FileProvider (`<applicationId>.app8.photos`) and a `<queries>` entry for `IMAGE_CAPTURE`. `scripts/render.sh` takes `PKG`.
- iOS simulator only: `APP8_SIMULATOR_CAMERA_IMAGE=<file>` stands in for the simulator camera (which takes no pictures) after the permission check.
