Minor release on 0.6.8. All SDKs move to 0.7.0 together (iOS, Android, web renderer).
- Vertical paging collections: `pagingStyle: "paging"`, `itemHeight` (a number or `"fill"`) and `currentPageVariable` on `type: "vertical"`; one page per swipe or flick, pages run edge to edge without automatic safe-area insets. A numeric `itemHeight` on a plain vertical list is now honored on every platform.
- `if` action: `condition` evaluated once, then `then` or `else` in the current scope; nests in `forEach`, `with` and other `if` actions.
- Unknown action types are skipped with one diagnostic; the rest of the action list and the screen run as usual (earlier iOS and Android releases rejected the screen).
- One boolean coercion for every boolean (`if`, `isHidden`, `isEnabled`, toggles and all other boolean properties): `true`, non-zero numbers, `"true"` / `"1"` and non-empty arrays or objects are true; any other string, `0` and `null` are false; a missing or unevaluable value keeps the property's default. Android no longer reads `"yes"` as true.
- `stackView` `style.layoutMargins`: arranged subviews inset by `top`, `leading`, `bottom`, `trailing`; the background still covers the full frame.
- Expression functions `sortBy(array, key, ascending)` (stable, dot paths, numbers before strings, code point order, missing last) and `merge(a, b)`.
- Array and object literals in expressions (`{{[ {title: 'A'}, {'title': 'B'} ]}}`); a `}}` inside braces or quotes no longer ends an expression.
- `navigationBar.title` is an expression that updates when its variables change.
- `image` without `type`: `url` is a remote asset (a relative `url` is a bundle file), `asset` or `name` a local asset.
- Bundle fonts: the fonts manifest is documented; the web renderer registers manifest font files with `@font-face`.
- `button` `isEnabled`: the boolean coercion; a disabled button runs no actions and fires no tap analytics.
- Collections: section headers in `grid` layouts (`groupBy`, `sectionDefinitions`), `section.items` in header scope, and `groupBy` given as a bare path (`item.category`) groups as documented.
- iOS source break: the public `ExpressionNode` enum gains `.objectLiteral`; code that switches over it exhaustively needs a `default` case.
