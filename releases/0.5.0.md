Minor release of the iOS + Android train (spec: https://github.com/appeight/app8-dsl/releases/tag/0.5.0). New commerce building blocks.
- `contextMenu` on views, images and buttons: long-press preview with menu items and `onPreviewTap`. iOS `UIContextMenuInteraction`; Android quick-view bottom sheet.
- `zoom` transition with `sourceKey`: the incoming screen grows out of a keyed element and shrinks back on interactive dismissal. iOS 18 `preferredTransition = .zoom`; Android shared bounds.
- `scrollView` pinch zoom (`minimumZoomScale`, `maximumZoomScale`, `doubleTapZoom`) and `stretchesTopChild` (iOS stretchy header; Android keeps system stretch overscroll).
- `picker` menu look (`style.label`, `style.indicator`) as a plain pull-down button, and `bindKey` to keep a choice per item in an object variable.
- Tab bar `badgeColor` and `badgeTextColor` (bar and per tab).
- App variables with `persist: true` keep their value across launches.
- Expressions: `map[key]` reads an object property by key.
- `updateVariable` `key` sets one key of an object variable.
- Horizontal collection `itemWidth` / `itemHeight` accept `"fill"` (full-frame pager items).
- Collection `currentPageVariable` is two-way: writing the variable scrolls the collection to that page.
