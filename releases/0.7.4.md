Patch release on 0.7.3. All SDKs move to 0.7.4 together (iOS, Android, web renderer). `DSL_VERSION` stays 1.1. The fixes are iOS-only; Android and the web renderer already behaved this way.
- Labels: `properties.numberOfLines` sets the maximum number of lines (0 = unlimited) and wins over the text style's `numberOfLines`, as [styles.md](../docs/styles.md) specifies. iOS used to read it only from the text style. A wrapping label inside an animated `isHidden` reveal settles its wrapped height before the animation.
- iOS 26 top scroll-edge effect ([navigation.md](../docs/navigation.md), `topEdgeEffect`): hidden at rest; it fades in over 16pt once content reaches the bottom of the bar. Over a hero (a full-width view from the screen's top edge, taller than the bar, e.g. an edge-to-edge carousel) it starts when the hero's bottom reaches the bar's bottom; otherwise when the first content does. Same rule as Android and the web renderer. `soft` and `automatic` draw a soft blur, `hard` a band with a hairline, `hidden` nothing. Earlier iOS versions are unchanged.
